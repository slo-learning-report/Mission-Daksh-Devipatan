# मिशन दक्ष – दक्षता रिपोर्ट

Public dashboard showing the results of the Mission Daksh oral assessment (Class 1 and Class 2) by janpad, block and school, with downloadable PDF reports.

* The page shows **only summary percentages**. It contains no child names, ages, IDs or any child-wise data.
* The one data file is `data/summary.json`. It is replaced whenever new results are published.
* `index.html` is the whole dashboard. It only displays the data; it has no login and no admin section.

Website: see the "About" box of this repository for the address.
